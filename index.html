01 The Problem

What This Solves

Field teams regularly need to access, configure, and troubleshoot computers and IoT devices that have no monitor, keyboard, or mouse attached. Whether the device is completely offline or running on its own network connection, the blocker is always the same: no way to see the screen or interact with the machine without hauling peripherals to the site.

🖥️

No screen on headless devices

Field computers and IoT units often run without displays. Troubleshooting currently requires borrowing a monitor or being near a full setup.

🌐

No internet at client sites

Many facilities have restricted or no network access. Remote desktop solutions (TeamViewer, RDP) simply don't apply in these environments.

🧳

Gear overhead

Carrying a spare keyboard, mouse, and monitor to every site is impractical. It slows deployments and adds failure points to every visit.

⏱️

On-site time wasted

Techs spend time locating peripheral equipment instead of doing the actual work. Billable time burns while scrambling for a spare monitor.

02 The Solution

NanoKVM-USB — Finger-Sized Control

The Sipeed NanoKVM-USB is a tiny aluminum device (~55mm long) that plugs into any target machine via HDMI and USB-C. It captures the video output and emulates a keyboard and mouse. Your laptop connects to it directly via a second USB-C cable and controls the target machine through Chrome — completely offline, no software, no network required on your end.

This solution works regardless of the target device's network status. The KVM operates at the hardware layer only — it does not touch, interrupt, or depend on any network connection the target machine may have.

📡
Scenario A — Device has an active network connection: The target machine continues running on its own network as normal. The KVM plugs in purely to give you a screen and peripherals on your laptop. When you unplug and walk away, the device carries on completely unaffected.
🔌
Scenario B — Device is completely offline: No network anywhere on site. The KVM still works because it connects directly to your laptop over USB-C with no network required. Full control in a completely air-gapped environment.
💡
Key insight: Your laptop's HDMI port is output-only and cannot receive video from another machine. The NanoKVM-USB acts as the bridge — it captures the target's video over HDMI and delivers it to your laptop over USB-C. The target machine has no idea it isn't connected to a real monitor, keyboard, and mouse.

04 Setup Instructions

Field Setup — Under 5 Minutes

No software installation on either machine. No network configuration. No accounts. Just cables and Chrome.

1
Install the HDMI Dummy Plug on the target device
Insert the dummy plug into the HDMI port on the target machine. It stays there permanently. It's passive and uses no power. This ensures the GPU always outputs a video signal even with no physical monitor present.
2
Connect HDMI cable: target machine → NanoKVM-USB
Run the included HDMI cable from the target machine's HDMI output port into the HDMI IN port on the NanoKVM-USB (the side marked with an arrow pointing in). Any standard HDMI cable works.
3
Connect USB-C cable: target machine → NanoKVM-USB
Plug one end of the USB-C cable into the target machine's USB-C port, and the other end into the NanoKVM-USB TARGET USB-C port. This carries keyboard and mouse emulation signals. If the target only has USB-A, use the USB-C to USB-A adapter here.
4
Connect USB-C cable: NanoKVM-USB → your laptop
Plug the second USB-C cable from the NanoKVM-USB HOST USB-C port into your laptop. This is the only connection your laptop needs. It powers the NanoKVM-USB and carries the video and control signals.
5
Open Chrome and go to usbkvm.sipeed.com
On your laptop, open Google Chrome and navigate to usbkvm.sipeed.com. Allow camera and microphone permissions when prompted (the device appears as a USB video source). The target machine's screen appears immediately in the browser. Click the screen to pass keyboard and mouse control through to the target. Fully offline — no internet required after the first page load.
⚠️
Browser note: Must use Google Chrome desktop. Firefox and Edge do not support the Web USB API used by the NanoKVM-USB. Ensure Chrome is up to date on field laptops before deployment.

06 FAQ

Common Questions

Does this require any software installed on the target machine?
No. The NanoKVM-USB requires zero software on the target. It emulates hardware peripherals at the USB level, so the machine sees a monitor, keyboard, and mouse — no driver or agent needed.
Does this require an internet connection?
No. The KVM connects directly to your laptop over USB-C. No network, no hotspot, no router needed. The browser app at usbkvm.sipeed.com loads once and then runs entirely locally over the USB link.
The target device is online and running. Does the KVM affect its connection?
Not at all. The NanoKVM-USB operates purely at the hardware layer — HDMI for video, USB for keyboard and mouse. It has no interaction with the device's network stack or active connections. The device continues operating exactly as normal while the KVM is plugged in, and nothing changes when you unplug.
What if the target machine has no USB-C port?
Use the USB-C to USB-A adapter (Item 03). The NanoKVM-USB uses USB-C on its own connectors — the adapter bridges to USB-A on the target with no loss of functionality.
What resolution does it display at?
The dummy plug emulates a 1080p monitor, so the target machine outputs at 1920×1080. The NanoKVM-USB captures and delivers this at full 1080p in Chrome. Full 4K capture is also supported if a 4K dummy plug is used instead.
Can this be used to install an OS on the target machine?
Yes. The NanoKVM-USB has a USB-A port with a host/target switch. Insert a flash drive with an OS image, assign it to the host laptop, write the ISO using Rufus, then switch the drive to the target and boot from it — all without unplugging anything.
What's the latency like?
50–100ms — slightly slower than a direct display, but completely usable for configuration, file management, terminal sessions, and BIOS access. Not suitable for video editing or gaming, but that's not the use case here.
Is this the same as the NanoKVM Cube (ethernet version)?
No. The NanoKVM-USB connects directly to your laptop via USB-C with no network needed. The NanoKVM Cube connects via ethernet and requires both devices on the same network. For field use, the USB version is the right choice.
